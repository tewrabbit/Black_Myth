# 封魔敌人闪避系统说明文档

## 概述
本文档说明了为封魔敌人（ParagonFengMao）添加的闪避系统。该系统允许敌人在受到攻击时随机触发闪避动作，通过瞬移的方式躲避攻击，但不提供无敌帧保护。

## 功能特性
- 随机触发：敌人在受到攻击时有30%的概率触发闪避
- 瞬移躲避：闪避时敌人会瞬间移动到附近的某个位置
- 冷却机制：闪避有2秒的冷却时间，防止连续触发
- 无无敌帧：与玩家角色不同，敌人闪避时不获得无敌状态

## 配置参数
可以在Unreal Editor中调整以下参数：

| 参数名 | 默认值 | 描述 |
|--------|--------|------|
| DodgeChance | 0.3f (30%) | 触发闪避的概率 |
| DodgeDistance | 300.0f | 闪避移动的距离 |
| DodgeCooldown | 2.0f | 闪避冷却时间（秒） |

## 实现细节

### 核心函数
1. `TryDodge()` - 检查是否可以触发闪避并随机决定
2. `PerformDodge()` - 执行闪避动作，计算闪避方向并瞬移
3. `FinishDodge()` - 结束闪避状态，恢复正常的AI行为

### 闪避方向策略
- 70%概率向侧面或后面闪避（远离玩家）
- 30%概率向任意方向闪避
- 闪避方向会考虑玩家位置以实现更智能的躲避

### 状态管理
- 添加了新的AI状态：`EFengMaoAIState::Dodge`
- 闪避期间敌人不会执行其他AI行为
- 闪避结束后自动回到巡逻状态

## 使用说明
1. 闪避功能已自动集成到受伤处理流程中
2. 当敌人受到攻击时，系统会自动调用闪避检查
3. 无需手动调用闪避函数

## 注意事项
- 闪避不提供无敌帧，仅为位置转移
- 闪避使用瞬移而非平滑移动，以实现快速躲避效果
- 闪避冷却时间防止过于频繁的闪避行为
